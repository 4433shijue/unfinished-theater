# 六选项人工评阅样例

以下是固定评阅场景和预期区别，供检查提示词效果。它们不是实际模型生成结果，也不写入玩家剧情。

| 场景 | 六个不同方向（A → F） |
| --- | --- |
| 日常茶馆，茶凉了 | 请店家换热茶；邀请邻桌分享点心；寻找后院异常声响；主动替忙乱店家接一桌客；用现有纸笔办一场茶名竞猜；给这杯凉茶举行一本正经的退休仪式，邀请店家致辞。 |
| 离别雨夜，关系尚未确定 | 说一句挽留；陪对方走到车站；询问这次离开的真正顾虑；坦白自己原本也准备离开；提议交换一件随身小物，约定下次来取；给门口空椅子配音，让它正式投诉客人擅自离席。 |
| 古代城门被挡，门口有石狮 | 办路引手续；护送受阻旅人找住处；调查封城规律；当众要求负责人解释收费；摆摊代写申诉并收集见闻；申请担任石狮替班，摆好姿势等守卫安排值守。 |
| 仓库对峙，双方缺乏信任 | 提出停战条件；保护旁边的无辜者撤退；检查双方争夺的箱子；公开揭穿已知的矛盾证词；提议把现场清点交给共同认识的第三人；把双方争吵当成仓库交接会，拿现有账本认真给对手分配盘点任务。 |
| 资源不足，只剩两枚钱 | 买最需要的食物；找熟人换一顿饭；打听短工；出售自己确实拥有的闲置物；用已有特长提供服务；替街边招财猫做一刻钟代班，向店主认真提出包饭条件。 |
| 严肃悬疑，废宅内有回声 | 检查门窗；护送惊慌同伴出去；循回声寻找夹层；主动喊出已知线索试探回应；利用现有器物测试声音传播；向看不见的“住户”郑重递交噪音投诉，观察对方是否回应。 |

检查每一对选项是否至少在目标、手段、对象、后续局面中的两项不同。E/F 的物件和能力必须在场景中成立；“突然得到法术”“直接知道凶手”“说完所有人都同意”都不合格。

递进不要求越来越暴力或越来越危险。F 的离谱行动被选中后仍然进入主线，NPC 可以拒绝、误解、认真配合或产生意外反应，不能一句“你开了个玩笑”就抹掉玩家行动。
