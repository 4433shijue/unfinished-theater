# v2.15.0 文游创建、人物演化与回合结算

版本为 `2.15.0+2150`，基线为 v2.14.0 的 `e2e3c78`。功能实现保存在 `codex/story-evolution-v215`，居中弹窗与皮肤补充在独立分支 `codex/story-evolution-skins-v215` 完成。

## 创建文游

创建页的“高级设置”默认收起，可设置视角、篇幅、节奏、互动偏好、世界约束、额外指令和初始人物数量。指令保留原文，包括换行和空格，并参与创建与后续回复。临时导演指令不能静默覆盖这些长期约束；程序协议与固定事实确认仍由应用管理。

短篇目标 600–1000 字，中篇 1200–1800 字，长篇 2200–3200 字。群聊仍使用气泡，不套用普通正文篇幅。

完整文游和盲盒默认生成 3–6 名 NPC，也可指定 3、4、5 或 6 人。开局预览可编辑人物、关系、物品及玩法，锁定满意部分，单独重做一个人物或一部分。作者查看秘密的入口标注剧透，展开它不会改变玩家知情状态。未登场人物不会提前出现在玩家的人物列表中。

手动创建可以主动生成开局。“只生成世界设定”默认不开启人物及玩法生成。旧世界可主动补全，并勾选需要添加的人物、物品或玩法；已有同名内容保留。取消创建不写入世界；验证或保存失败保留当前对话框草稿，显示缺项或错误，不自动循环调用模型凑齐。

## 人物演化

同一个 NPC 保持稳定 ID。身份揭露或改名会保存过去的称呼与发生回合，不新建重复人物。公开身份、秘密是否揭露、登场、目标、立场、好感、信任与经历按世界保存；基础角色卡和世界经历分开。

AI 提交的死亡、失踪、恢复或身份变化，需要本轮正文中的明确证据。传闻、猜测和计划不直接成为事实。涉及锁定事实的冲突进入已有确认流程。死亡或失踪人物停止正常私聊与主动来信，不能继续累加关系变化。

当游戏内时间明确推进时，最多两名人物各推进一步日常行动。移动、工作、调查及普通交往可以后台进行；重大事件保存为待展开线索。未公开行动不进入玩家结算，私聊只注入该人物本人的后台信息。系统不会按现实时间自动运行。

承诺与余波沿用现有台账。明确的回合期限可以提醒到期；“明晚”等无法换算成回合的原文仍保存，但不擅自推断具体回合。到期提醒本身不会自动判定失约。

## 每回合结算

正文与状态提交成功后，自动展示一次结算。手机和桌面均使用悬浮在整个界面正中央的小窗口；窗口四周保留留白，内容过长时在窗口内部滚动。结算列出实际变化、前后值、变化量和原因，覆盖玩法、物品、好感、信任、身份、生死、任务、事件、承诺及余波。没有公开变化时明确说明。

关闭后可从该条回复的“本回合结算”入口重看。刷新、重新进入或导入存档不会重弹已读结算；在其他页面完成的回合保留未读状态，返回对应故事再展示。

结算失败会保留正文并显示“结算未完成”，暂停下一回合。可重试结算或回到上一回合。重试沿用原正文；地图已经计算的行动费用沿用候选结果，避免再次扣费。若存储设备持续拒绝所有写入，则无法保证跨重启保存，界面会保留错误而不宣称提交成功。

主线、地图和群聊使用统一结算；NPC 私聊保留独立记录，同时写入所属世界快照。删回合、重生成、分支及读档恢复相应人物、物品、认知和承诺。历史结算保存当时公开的信息，不动态引用后来揭露的身份。

结算、创建、高级设置、开局预览和编辑窗口沿用当前皮肤的面板、边框、字体及按钮；自定义主题使用自己的配色与圆角。
