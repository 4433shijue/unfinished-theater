# 未完剧场 3.0 · 下一步，由你决定

本次 3.0 使用 2.16 的对话布局。小说手账方案已撤回，不合并双页、书架、续写抽屉及其导航。新版本号为 `3.0.0+3001`，高于曾生成的手账候选包 `3.0.0+3000`；代码基线为 `947db36`，分支为 `codex/story-expression-v3`。

## 已实现

| 范围 | 行为 |
| --- | --- |
| 玩家决定权 | 主线、地图、大型群聊、人物私聊、开场、格式修复、局部改写共用约束。只兑现本轮提交，不将历史引用、预演、未选路线和 NPC 邀请视作玩家同意。必要过程和已授权的复合行动可以完成，遇到新取舍即停。 |
| 长度与结算 | 字数为场景展开目标，允许在下一次决定前提前结束。地图不再因短于字数下限单独触发补写。原有结算请求增加授权核对，没有增加审核请求。 |
| 历史缓存 | 新请求单列本轮提交；旧存档的重生成保留冻结上下文，并补上行动边界。提供方助手原文回放逻辑保持兼容。 |
| Markdown | 普通段落、少量加粗与斜体、信件引用、确有换场时的小标题。模型不输出字号或颜色代码，不强制每轮套模板。 |
| 主题对白 | `“”`、`「」`、`『』` 和英文双引号自动着色。对白可跨加粗、斜体和链接文字；代码、图片地址和链接目标不着色。未闭合的流式引号不会把后续段落染色。 |
| 字号层次 | 标题限制在正文的 1.15–1.25 倍，强调 1.08 倍，弱化 0.95 倍；沿用现有字体与缩放。 |
| 配色 | 以当前皮肤主色为基础，按实际气泡底色调深或调浅，保留色相。普通正文已足够清晰时保留原色。半透明气泡先合成底色；跨明暗的极端渐变无法满足统一对比度时选择最清晰的同色相颜色。 |
| 文字操作 | 选中显示文字后映射回 Markdown 原文，保留未选部分格式。重复文字仍要求选择具体位置；找不到时不给默认替换。引用及复制使用可阅读文本，来源校验仍基于原文。 |
| 导出 | HTML 导出使用当前皮肤与气泡配色；分享卡按自身浅色纸面适配同一主题色。群聊保留发言人、正文和格式。HTML 番外继续使用原有沙箱。 |
| 布局与存档 | 沿用旧布局、皮肤、贴图、装扮、输入和六选项操作。A–F 差异与递进意外策略沿用 2.16。存档 schema 仍为 5，显示时不改写存储正文。 |

## 验证方法

- `flutter analyze --no-pub`。
- `flutter test --no-pub`，包括请求约束、缓存、NPC 隔离、结算、长历史锚点、重复选文、分支、皮肤与宽窄布局回归。
- `flutter test --no-pub tools/story_expression_browser_fixture.dart` 生成纯模拟数据。
- `node tools/story_expression_browser_qa.cjs` 对正式 Web 构建进行浏览器验收。环境变量 `THEATER_PLAYWRIGHT_MODULE`、`THEATER_CHROMIUM_PATH`、`THEATER_QA_URL` 指定本机工具与候选预览。
- `tools/story_expression_compatibility_fixture.dart` 在真实 2.16 与 3.0 两套代码下依次执行 seed / upgrade / rollback，使用 `EXPRESSION_COMPAT_MODE` 和 `EXPRESSION_COMPAT_DIR` 指定阶段和独立数据目录。

测试与浏览器请求均使用模拟数据和模型。请求检查证明规则进入了相应调用链，不能证明任意真实模型绝不越界。真实模型文风、遵循率和 Android 真机体验分别记录，不能由构建成功替代。

候选包验收后再决定正式发布；本次不替换线上网页版。
