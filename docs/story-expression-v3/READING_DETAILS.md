# 正文阅读细节：本地验收

本次是保留 2.16 布局的正文显示更新，不改存档结构，不覆盖已发布网页。黑胶沿用深棕阅读面；主线书面道具和 NPC 私聊是不同的渲染路径。

## 样章和兼容

使用普通 Markdown 引用块，第一行只放加粗的「来信」「纸条」「短信」或「广播」，后续引用行是实际内容。未标类型的旧引用不推测用途。不从道具创建 NPC 消息、事实或剧情选项。

选区复制及「摘进书签」恢复完整对白的原始引号，选中半句不补引号。书签复用原备注，只有点击保存才落盘。返回定位线是临时界面状态；当前消息不存在、段落被改写或文字重复时不标记。

## 验证记录

- Flutter 全量测试：488 项通过，1 项按配置跳过（需要外部模型的评测）。静态检查通过，Web release 构建成功。
- Chromium 本地生产构建：1280 和 390 像素宽度跑通主线回复、进入 NPC 私聊、回复与返回主线；返回没有新增模型请求。生成使用模拟端点。
- 240 条旧消息的回看、群聊发言人、窄屏 1.25 倍字号通过浏览器验证；流中断、复制段落和还原引号、书签取消、锚点删除及重复段落不误标另有 Flutter 测试。
- 同一份「渡口来信」实际渲染出 14 套桌面皮肤、1 张黑胶大字号窄屏和 1 张 NPC 私聊截图。所有默认皮肤的旁白、对白、强调和弱化文字按气泡渐变底色验证至少 4.5:1。
- 未用真实模型评估格式选择频率，未做 Android 真机验收，未发布。

## 复现图册

先运行 `flutter test tools/story_expression_browser_fixture.dart` 生成合成存档，构建并启动本地 Web 版。将 `THEATER_QA_URL` 指向该地址，按需设置 `THEATER_PLAYWRIGHT_MODULE`、`THEATER_CHROMIUM_PATH` 与 `THEATER_ATLAS_OUT`，运行 `node tools/story_reading_atlas.cjs`。输出的 `index.html` 内嵌全部图片，可以离线打开。
