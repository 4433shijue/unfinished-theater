# v2.14.0 使用说明

本版增加局部重写、重要事实、持续导演偏好、接戏卡与阅读恢复、人物知情范围、场景章节。所有记录按剧本及 IF 分支保存。

## 精修一句话或一段剧情

在正文选中文字，使用「局部改写」；手机可以长按。也可以从消息菜单进入，使用「选择段落」。普通正文、分段气泡、群聊单条发言和 NPC 私聊都支持。状态协议和 HTML 番外不参与选段。

选择「润色文字」或「改写剧情」，填写要求，生成后先比较原文与候选文字。取消不修改聊天。候选绑定生成时的消息内容；原文变化后需要重新生成。

润色通过状态核对后可直接采用，并在该消息的版本列表切换。事实发生变化，或不能确认事实保持一致时，采用候选会创建 IF 分支。分支恢复目标回合前的状态，重新结算改动的回合；后来的主线与私聊不会进入旧分支。NPC 私聊分支保留同批回复中未改动的气泡。

旧记录缺少可靠快照时，界面列出可保留内容与缺失状态，并要求填写起点人物好感。未知印象、经历与羁绊不会套用当前关系。地图时间、地点仍由地图规则管理，改写不能直接绕过移动或时间推进。

## 记住重要事实

在消息菜单选择「记为重要事实」，或在记忆库／「接戏卡 → 事实、知情与章节」中新增。来源、适用世界、生效位置与修订一起保留；可查看原文、解除固定、修改。

模型的常规整理可以增加普通事实，但不能覆盖已固定事实。冲突进入待确认列表，同一冲突去重。纠错会先展示关联记忆与人物知情记录，再选择：

- 「以前记错了」修订已有记录和对应历史快照中的事实。
- 「剧情现在变化」从当前位置建立新版本；人物对新版本的认知重新等待确认。

原聊天正文保留。来源删除、改写或缺失后，相关事实标记为待核对，并停止作为已确认依据注入模型。重要事实不覆盖玩法资源、地图或程序数值。

## 持续导演偏好

从导演台或接戏卡进入「导演偏好」，设置剧情节奏、对话比重、心理描写、篇幅及自由补充。

「本回合」优先于「本场景」，再继承「本剧本」。空项继承下一级。生成成功才消耗本回合设置；失败保留。场景收尾后清除本场景设置。本剧本设置持续保存，NPC 私聊也参考它，同时保持聊天气泡格式。

## 接戏与阅读

主线右上方的「接戏卡」展示有来源的场景、在场人物、最近事件、未解决事项和待回应内容；点击对应条目可以定位原文。没有依据的项目保持空缺。离开剧本超过 24 小时后，首次返回自动展开一次。

阅读位置按世界、分支和 NPC 私聊保存，包括消息及消息内位置。书签和来源跳转使用实际布局定位，适应长消息和字体变化。阅读旧内容时，新回复不会强制拉到底部；点击「有新内容」才回到最新。原锚点已删除时寻找最近保留的消息。

## 人物知道什么

在 NPC 详情或「事实、知情与章节 → 知情」查看、纠正亲见、被告知、怀疑、未知。怀疑和传闻不自动当作确认事实。NPC 私聊使用该人物明确可知的事实、当前世界关系及私聊经历。

世界书和玩家设定可选择「公开」「指定 NPC」「仅叙事后台」。旧条目默认只供主线使用；如需人物知道，请明确修改公开范围。同一人物共享身份与人设，各世界的经历、关系和私聊独立；「带 TA 走」继续按所选记忆继承策略处理。

## 收尾与章节

「事实、知情与章节 → 章节 → 在这里收尾」会请求一段约 200—400 字的收束，可保持开放结尾，不替玩家承诺或解决冲突。成功后保存章节标题、起止消息、回顾与遗留事项；失败保持场景开放。关闭章节不额外重复结算玩法回合。

之后可停留阅读、重新打开当前场景，或选择「进入下一场」。下一场可延续当前位置、指定时间或地点。地图模式一次选择移动或推进时间，继续检查可达性、行动成本和剧情时钟。章节可改名并跳转到开头。

## 数据与本地运行

升级前建议导出完整存档。新存档为 schema 3；迁移细节见 [迁移说明](V2_14_0_MIGRATION.md)，验证范围见 [验收报告](V2_14_0_VALIDATION.md)。

Web 构建解压后通过 HTTP 服务打开，例如在解压目录执行 `python -m http.server 8924 --bind 127.0.0.1`，访问 `http://127.0.0.1:8924`。浏览器存档跟随站点来源，换端口或域名前先导出存档。APK 为本地验收包，签名情况见验收报告。
