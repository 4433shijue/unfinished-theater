渡口来信

一段未完的故事
THE UNFINISHED THEATRE港口 · 夜雨
VII

雨停之前

有人在等一封不该寄出的信

雨沿着棚檐落下来，整条河像一封没有写完的信。

我把信放在灯下，等他先开口。

阿澈没有看信。他先看了看我，又看向远处迟迟不肯靠岸的船。指尖按住信封一角，像按住一个快要说出口的秘密。

「如果这封信，是明天的你寄来的呢？」

远处传来第三声汽笛。我可以拆开它，也可以先握住那只一直没松开的手。
