# 未完剧场 · 三套布局原型

双击 `index.html` 查看三个方向，或直接打开任意一份原型。三个原型 HTML 均内嵌 CSS、JavaScript 和图片，可以分别复制到别处离线打开，无需安装依赖或启动服务器。入口页需要与三个原型放在同一目录。

| 原型 | 桌面 | 手机 |
| --- | --- | --- |
| 01 故事现场 | 左侧故事导航，中央正文独立滚动，底部常驻输入 | 收起侧栏，正文与底部输入分开 |
| 02 小说手账 | 左页阅读，右页选择与书写，侧边书签 | 上下两页，底部书签跳转 |
| 03 舞台剧场 | 大场景，下方分栏对白与选择 | 逐段对白，路线与输入放进底部抽屉 |

三套均复用项目的「雨巷电台」「花非花」「黑胶往事」横竖背景及按钮 normal/hover/pressed 原图，可在页头切换同一皮肤对比布局。为保持离线便携，字体采用系统楷体、宋体及中文无衬线字体。

可操作的内容包括六路线多选、移除选择、换一组六个方向、自由输入、引用、灵感草稿与撤回、人物私聊、章节回看、私人手记和皮肤切换；舞台版额外支持逐段阅读。六条路线分别展示查线索、关系、交易、换场景、反转和荒诞意外，F 仍承接当前码头/信件情境。示例多选回复会按选择顺序展示各路线的预置片段，不代表真实模型的剧情融合质量。

原型不连接 AI，不读取正式应用数据。手记与皮肤保存在每套原型独立的 localStorage 中；浏览器禁用存储时仍可使用主要交互，保存失败会明确提示。正文、私聊与草稿只在本次页面会话里演示，刷新重置。

## 重建

在仓库根目录运行 `python docs/ui-layout-prototypes/build_prototypes.py`。维护源文件位于 `src/`，生成的三个 HTML 才是交付文件。入口缩略图优先使用 `build/ui-prototype-qa/1-desktop.jpg` 至 `3-desktop.jpg`；不存在时使用原有皮肤背景。

这些原型独立于 Flutter 正式界面，没有替换生产代码。

## 验证

在 Chromium 中以 `file://` 直接打开三份交付文件，检查 1440×1000 桌面与 390×844 手机视口下的多选、取消、发送、引用、换选项、保存手记、草稿撤回、人物私聊、皮肤切换与弹层关闭。六组均通过，未发出外部网络请求、无 JavaScript 异常。另检查 320、760、820、1024 像素宽度，无横向页面溢出；已人工查看桌面与手机截图。手机验证使用浏览器视口模拟，未做实体手机验收。
