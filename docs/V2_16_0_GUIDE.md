# v2.16.0 接话与六选项

## 聊天时随手使用

选中正文后点「接这句」，或从消息菜单选择一段。输入框显示引用，可取消、查看来源；发送后与消息一起保存。原文被改动或删除时，待发送引用需要重新选择。

输入框的「写作小工具」提供「帮我说出来」和「私人便签」。先写自己的意思，再让 AI 给出两种短表达，点选后仍可编辑、恢复原稿，最后自己发送。每次点击生成会调用当前主模型，不收取啥币。

每个剧本和分支有独立便签，自动保存在本地。选中文字后可带入输入框或导演台；没有选中文字时使用整张便签。便签不会自动发给模型或进入长期记忆。新建分支会复制便签，输入草稿则清空。

导演台可以点选常用短语，把当前导演补充保存成自己的短语，或编辑、删除已有短语。短语库在不同剧本之间共用，应用范围沿用本回合／本场景／本剧本设置。

NPC 详情的「专属称呼」可以填写双方称呼和使用条件。称呼只用于当前世界，不会替换人物正式姓名，也不会自动把朋友变成恋人。留空即可恢复自然称呼。

## 六条不同的路

A 到 F 的意外程度逐步增加，具体行动不固定职业或玩法分类。六项应在目标、手段、对象和后续局面上拉开差异，同一句话换语气不算一条新路。

F 可以非常荒诞，但仍是在当前世界里可以尝试的行动。人物会认真回应，实际费用、规则和后果仍然生效。选项描述尝试，不预告成功。

仍然可以多选，并在输入框里编辑、调整顺序。能连贯完成的行动依次尝试；真正互斥的行动需要玩家取舍。教程保持三项，地图及大型群聊继续使用各自的交互方式。

最新普通剧情回复提供「换一组选项」。它只重新生成六项，不重写正文、不重新结算。本次结果无效或剧情已经变化时，保留原组选项。换成功后清除旧勾选，手写草稿保留。

选项在原生成请求内自检，程序检查数量、字母顺序和明显重复，不增加每轮固定审核请求。语义差异及创意质量仍取决于所连接模型；「换一组选项」按需调用一次模型。

## 阅读与存档

普通结算默认显示在正文下面，点开查看完整明细。人物生死／失踪、任务完成、承诺兑现／失约会突出显示；结算失败继续保留重试、回退和暂停推进的保护。在「设置 → 显示与交互」可恢复每轮完整结算弹窗。

存档 schema 升级为 5，旧存档可导入。引用、有效选项、草稿、便签、称呼和常用短语随对应存档保留；旧版本不能读取新版存档。编辑数据独立于剧情快照，不作为已经发生的故事回放。

草稿保存失败时保留输入内容并允许重试；成功加入聊天后才清空输入框。本地保存仍需配合导出备份。
