# v2.15.0 居中弹窗与皮肤补充验收

日期：2026-10-27。基于功能提交 `8ac5af9`，工作分支为 `codex/story-evolution-skins-v215`。版本仍为首次发布到网页的 `2.15.0+2150`。

## 本次调整

- 手机与桌面都通过根导航层弹出居中结算窗口，限制宽高、保留四周留白，长内容在窗口内部滚动，关闭按钮与继续阅读保持可用。
- 创建窗口、人物编辑、关系与物品编辑、玩法变量编辑采用同一套故事弹窗；高级设置、开局预览、作者秘密查看与人物剧情档案采用当前皮肤的面板。
- 复用皮肤配色、异形边框、圆角、字体、按钮及图标贴图。弹窗面板不透明，避免底下的正文透进来；自定义主题使用其配色和圆角。
- 修正裂隙皮肤中短按钮过窄导致的九宫格贴图断言；只在这些故事工具里增加必要的按钮最小宽度。
- 创建时已经保存开局玩法的故事，不再显示多余的“生成玩法”提示按钮。
- 人物、物品和玩法变量的编辑表单增加顶部留白，避免首个输入框的浮动标签被滚动区域裁掉。

使用 Edge 独立上下文与虚构存档，1280×950、390×950 两个尺寸。覆盖樱花、愚人节特调、深渊观测站、裂隙中转站、花非花、机械迷城、雨巷电台、晴空牧场、黑胶往事及自定义纸笺主题。其余预设配色由组件测试覆盖。

每种尺寸检查自动结算、关闭后刷新不重复弹出、高级设置原文保存、生成三个 NPC、作者查看秘密、锁定人物、局部重新生成、人物编辑窗口、创建保存，以及玩家人物页的保密情况。模型请求全部由本地固定响应替代，真实模型调用为零。

20/20 个主题与尺寸组合通过，页面异常为 0。结果保存在 `build/story-skin-qa/browser-report.json`，截图按 `<主题>-<宽度>-<步骤>.png` 命名。结算与高级设置的十套主题截图已逐套查看；补齐表单留白后又复核裂隙和自定义主题的双尺寸流程。模拟器会按照实际皮肤生成界面标签，以适配换装后的称呼；愚人节皮肤沿用其原有故障文字设计。
