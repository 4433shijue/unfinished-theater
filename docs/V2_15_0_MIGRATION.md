# v2.15.0 存档兼容说明

导出存档格式从 v3 升至 v4，应用版本为 `2.15.0+2150`。导入仍支持旧版封装与旧根对象，保留原有历史、背包、人物与剧情进度。

新增数据包含 `StoryAdvancedSettings`、结构化 `StoryOpeningDraft`、NPC 的世界剧情状态、物品数量、承诺期限，以及消息快照内的 `TurnSettlement` 和修订历史。缺省字段使用兼容默认值，原有物品未记录数量时按一件读取。旧消息没有可靠快照时，不补造过去的变化记录。

共享角色的基础名称和简介保存为 `baseName`、`baseDescription`；世界中的改名、身份和经历仍保存于 `NpcWorldState`。旧卡缺少基础字段时，以迁移时的名称和简介作为基线，不猜测更早身份。新世界从基础卡开始，既有世界继续使用自己的快照。

旧文游不会自动生成新的 NPC 或玩法。用户主动发起补全后，只添加勾选的缺项。新回合开始记录完整结算。导入已有结算统一视为已读，避免批量重弹历史结果；未完成结算仍可从消息入口恢复处理。

正文、玩法、NPC、连续性和结算复用 `LocalStore` 的批量事务与恢复日志。一旦候选提交失败，运行时状态恢复到提交前；正文尽可能保存为待结算记录，重试不重新生成剧情。底层中断恢复、主线和私聊回退、分支与导出导入由自动回归覆盖。

局部改写或删除历史事件会重新应用后续已记录的变化，而非把当前人物状态直接塞入历史。历史结算保留当时的公开名称。缺少可靠旧快照时沿用既有的保守恢复与确认流程，不伪造过去的数值变化。
