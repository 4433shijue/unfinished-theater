# v2.14.0 验收报告

验收环境为 Windows、Flutter 3.41.7 / Dart 3.11.5、Edge Chromium。本次从干净的 `6c7c972cb1f68fbae6f9dcf4b4df237bb57e6dff` 工作副本创建 `codex/story-continuity-v214`，未在主目录实施代码改动。版本为 `2.14.0+2140`，存档 schema 3。

## 交付范围

| 功能 | 已实现与验证的行为 |
| --- | --- |
| 局部重写 | 普通正文、分段、群聊单条与 NPC 私聊定位；重复文字要求选择具体位置；预览不改原文；取消、过期候选拒绝、版本切换、失败回滚；事实改变进入独立 IF 分支 |
| 重要事实 | 固定、解除、来源查看、冲突去重；历史纠错与当前变化；来源删除／修改后待核对；不覆盖程序数值 |
| 导演偏好 | 本回合／本场景／本剧本逐字段继承；失败保留、成功消费；收尾清理场景设置；私聊采用剧本偏好 |
| 接戏与阅读 | 有依据的接戏卡；24 小时离开后返回展开；独立消息锚点与消息内位置；书签／来源定位；旧消息阅读不跟随流式输出；删除锚点寻找邻近消息 |
| NPC 知情 | 世界关系与共享人设分离；明确知情、怀疑、未知；实际请求排除其他 NPC 秘密、后台世界书、未来信息和旧混合归档；世界书／玩家设定公开范围 |
| 场景章节 | 收尾生成、成功后关闭、失败保留开放；章节起止、回顾、遗留事项、改名、跳转与重开；下一场使用既有地图／时间规则 |

旧档不执行全历史模型分析。混合私聊可读归档，旧共享关系明确标注升级基线；缺少可靠快照的改写由玩家补充必要起点好感，不借用当前数值。主动来信也保存改写所需快照。
